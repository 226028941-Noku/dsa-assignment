To run our integrated system on hp please do this:
  please download our whole file
  install javac
  open the folder in cmd
  check the java with code 
    java -version
    javac -version
  compile all the files
  then run java CampusServiceCentre

To run our system on MacOS:
  please point JAVA_HOME at homebrew's JDK 21 SO javac/java can work
  open the folder in terminal then run
export JAVA_HOME="/opt/homebrew/Cellar/openjdk@21/21.0.11/libexec/openjdk.jdk/Contents/Home"
export PATH="$JAVA_HOME/bin:$PATH"
then run
javac CampusServiceCentre.java WaitingLineQueue.java LinkedList.java SelectionSort.java InsertionSort.java MergeSort.java QuickSort.java
java CampusServiceCentre
